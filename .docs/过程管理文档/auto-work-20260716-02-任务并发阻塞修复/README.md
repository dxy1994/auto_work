# 任务并发阻塞修复

## 目标

修复网站账户监控期间商品刷新、订单提醒和自动招呼无法正确并发的问题，保证所有 Playwright 操作在浏览器会话所属事件循环执行，并避免同步语音阻塞监控协程。

## 成功标准

- 招呼浏览器协程运行于对应 `BrowserSession` 的所有者事件循环；
- 商品刷新运行时可立即创建独立聊天页面；
- TTS 播放不阻塞订单监控和商品刷新事件循环；
- 健康检查不会关闭正在使用的聊天临时页面；
- 不增加浏览器会话引用计数泄漏；
- 新增回归测试通过，Worker Python 文件编译通过。
