# 需求规格说明书（SPI-REQ-ConFix-SRS）V1.0

## 功能需求

1. 中控下发 `greeting` 后，Worker 不得等待商品刷新周期结束才开始招呼。
2. 同一网站账户的监控页、商品刷新页和聊天页共享 Cookie，但所有页面操作必须由同一个 Playwright 所有者事件循环执行。
3. 招呼使用独立聊天页，不得导航或占用订单监控页、商品刷新页。
4. 正在使用的聊天页不得被周期性多余页面清理关闭。
5. 文本语音提醒不得同步阻塞 asyncio 事件循环。
6. 浏览器会话不存在、事件循环已关闭或招呼超时时，应返回明确失败结果。

## 非功能需求

- 保持现有 WebSocket 协议和后端接口不变；
- 保持一个网站账户一个持久化浏览器上下文；
- 采用最小范围修改，不重构平台监控器业务逻辑；
- 招呼调度延迟目标小于 1 秒，不包含目标网站自身页面加载时间。

## 不在范围内

- 游戏客户端真实交易；
- 调整商品刷新周期；
- 修改中控订单状态机；
- 跨进程浏览器共享。
